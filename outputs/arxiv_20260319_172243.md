## 1. Search2Motion: Training-Free Object-Level Motion Control via Attention-Consensus Search
- Authors：Sainan Liu, Tz-Ying Wu, Hector A Valdez, Subarna Tripathi
- Comments：14 pages, 9 figures
- First：2026-03-17T16:02:38+00:00；Latest：2026-03-18T17:58:04+00:00
- Abs：https://arxiv.org/abs/2603.16711v2
- PDF：https://arxiv.org/pdf/2603.16711v2
- Code：https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces

**中文翻译**
- 标题：Search2Motion：通过注意力共识搜索实现免训练的对象级运动控制
- 摘要：我们提出 Search2Motion，这是一种用于图像到视频生成中对象级运动编辑的免训练框架。不同于以往需要轨迹、边界框、掩码或运动场的方法，Search2Motion 采用基于目标帧的控制方式，利用首末帧运动先验，在无需微调的情况下实现对象重定位，同时保持场景稳定性。可靠的目标帧构建通过语义引导的对象插入和鲁棒的背景修复来实现。我们进一步表明，早期步骤的自注意力图能够预测对象与相机动态，既提供了可解释的用户反馈，也启发了 ACE-Seed（用于早期步骤种子选择的注意力共识），这是一种轻量级搜索策略，无需前瞻采样或外部评估器即可提升运动保真度。注意到现有基准常将对象运动与相机运动混淆，我们引入了 S2M-DAVIS 和 S2M-OMB，用于稳定相机、仅对象运动的评测，同时提出 FLF2V-obj 指标，在无需真实轨迹的情况下分离对象伪影。Search2Motion 在 FLF2V-obj 和 VBench 上持续优于基线方法。

**Structured Analysis / 结构化分析**

**Motivation / 研究动机**
- EN: Object-level motion editing for image-to-video generation has relied on cumbersome motion specifications such as trajectories, boxes, masks, or dense motion fields, making control difficult for users. Existing evaluation settings also mix object motion with camera motion, obscuring whether methods truly improve object-level editing.
- ZH: 图像到视频生成中的对象级运动编辑一直依赖轨迹、边界框、掩码或稠密运动场等繁琐的运动指定方式，使用户控制成本较高。现有评测设置还常把对象运动与相机运动混在一起，难以判断方法是否真正提升了对象级编辑能力。

**Method & Architecture / 方法与架构**
- EN: Search2Motion is a training-free framework that controls motion by constructing a target final frame from first-last-frame priors, using semantic-guided object insertion and background inpainting to relocate objects while keeping the scene coherent. Its key novelty is ACE-Seed, which searches seeds via consensus in early-step self-attention maps that forecast object and camera dynamics, enabling better motion control without fine-tuning, look-ahead sampling, or external scoring models.
- ZH: Search2Motion 是一种免训练框架，通过利用首末帧先验构造目标最终帧，并结合语义引导的对象插入与背景修补，在保持场景连贯性的同时实现对象重定位。其关键创新是 ACE-Seed，它利用早期步骤自注意力图中的一致性进行种子搜索，这些注意力图可预测对象和相机动态，从而无需微调、前瞻采样或外部评分模型即可提升运动控制效果。

**Experiments / 实验结果**
- EN: The paper introduces S2M-DAVIS and S2M-OMB for stable-camera object-only evaluation, and proposes FLF2V-obj metrics to measure object artifacts without ground-truth trajectories. On these object-isolated metrics and on VBench, Search2Motion consistently outperforms prior baselines.
- ZH: 论文引入了用于稳定相机、仅评估对象运动的 S2M-DAVIS 和 S2M-OMB，并提出了无需真实轨迹即可衡量对象伪影的 FLF2V-obj 指标。在这些面向对象的评测以及 VBench 上，Search2Motion 均稳定优于现有基线方法。

**Limitations / 局限性**
- EN: Because the approach depends on constructing reliable target end frames and interpreting early attention behavior, its robustness may degrade when those priors or attention cues are inaccurate in complex scenes.
- ZH: 由于该方法依赖于可靠的目标末帧构造和对早期注意力行为的正确解释，当这些先验或注意力线索在复杂场景中不准确时，其鲁棒性可能下降。


## 2. The Unreasonable Effectiveness of Text Embedding Interpolation for Continuous Image Steering

**中文翻译**
- 标题：用于连续图像操控的文本嵌入插值的非凡有效性
- 摘要：我们提出了一个无需训练的框架，用于在测试时对文本条件生成模型进行连续且可控的图像编辑。不同于依赖额外训练或人工用户干预的现有方法，我们发现，仅在文本嵌入空间中进行简单操控，就足以实现平滑的编辑控制。给定一个目标概念（例如增强照片真实感或改变面部表情），我们使用大语言模型自动构建一小组去偏的对比提示词对，并据此在生成器的文本编码器空间中计算一个操控向量。随后，我们将该向量直接加到输入提示词表征上，以沿所需语义轴控制生成。为实现连续控制，我们提出了一种弹性范围搜索过程，可自动识别有效的操控强度区间，从而同时避免操控不足（无编辑）和操控过度（改变其他属性）。在该区间内加入同一向量的不同比例缩放版本，可得到平滑且连续的编辑。由于我们的方法只修改文本表征，因此能够自然泛化到不同的文本条件模态，包括图像和视频生成。为量化操控的连续性，我们引入了一种新的评估指标，用于衡量不同编辑强度下语义变化的均匀性。我们比较了各方法的连续编辑行为，发现尽管该方法简单且轻量，但其效果可与基于训练的替代方法相当，并优于其他无需训练的方法。
