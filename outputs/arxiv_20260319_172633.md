## 1. Search2Motion: Training-Free Object-Level Motion Control via Attention-Consensus Search
- Authors：Sainan Liu, Tz-Ying Wu, Hector A Valdez, Subarna Tripathi
- Comments：14 pages, 9 figures
- First：2026-03-17T16:02:38+00:00；Latest：2026-03-18T17:58:04+00:00
- Abs：https://arxiv.org/abs/2603.16711v2
- PDF：https://arxiv.org/pdf/2603.16711v2
- Code：https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces

**中文翻译**
- 标题：Search2Motion：通过注意力共识搜索实现免训练的对象级运动控制
- 摘要：我们提出 Search2Motion，这是一种用于图像到视频生成中对象级运动编辑的免训练框架。不同于以往需要轨迹、边界框、掩码或运动场的方法，Search2Motion 采用基于目标帧的控制方式，利用首尾帧运动先验，在无需微调的情况下实现对象重定位，同时保持场景稳定性。通过语义引导的对象插入和稳健的背景修复，可实现可靠的目标帧构建。我们进一步表明，早期步骤的自注意力图能够预测对象与相机动态，提供可解释的用户反馈，并由此提出 ACE-Seed（用于早期步骤种子选择的注意力共识），这是一种轻量级搜索策略，可在无需前瞻采样或外部评估器的情况下提升运动保真度。注意到现有基准混淆了对象运动与相机运动，我们引入了 S2M-DAVIS 和 S2M-OMB，用于稳定相机、仅对象运动的评估，并提出 FLF2V-obj 指标，在无需真实轨迹的情况下分离对象伪影。Search2Motion 在 FLF2V-obj 和 VBench 上持续优于基线方法。

**Structured Analysis / 结构化分析**

**Motivation / 研究动机**
- EN: Object-level motion editing in image-to-video generation usually depends on explicit trajectories, boxes, masks, or motion fields, making control cumbersome and less accessible. Existing evaluations also mix object motion with camera motion, obscuring whether methods truly improve object-specific editing quality.
- ZH: 图像到视频中的对象级运动编辑通常依赖显式轨迹、框、掩码或运动场，导致控制过程繁琐且可用性较差。现有评测还常将对象运动与相机运动混在一起，难以判断方法是否真正提升了对象级编辑质量。

**Method & Architecture / 方法与架构**
- EN: Search2Motion is a training-free target-frame-based framework that relocates objects using first-and-last-frame motion priors, with semantic-guided object insertion and background inpainting to build reliable target frames. Its main novelty is ACE-Seed, which searches early-step self-attention consensus to pick better seeds for motion generation without look-ahead sampling or external scoring models.
- ZH: Search2Motion 是一种免训练的基于目标帧的框架，利用首尾帧运动先验进行对象重定位，并通过语义引导的对象插入与背景修复构建可靠的目标帧。其主要创新是 ACE-Seed，通过搜索早期步骤自注意力的一致性来选择更优随机种子，从而在无需前瞻采样或外部评分模型的情况下提升运动生成质量。

**Experiments / 实验结果**
- EN: The paper introduces S2M-DAVIS and S2M-OMB for stable-camera object-only evaluation, and proposes FLF2V-obj metrics to measure object artifacts without ground-truth trajectories. On these new protocols as well as VBench, Search2Motion consistently outperforms prior baselines.
- ZH: 论文提出了用于稳定相机、仅评估对象运动的 S2M-DAVIS 和 S2M-OMB 数据集，并设计了无需真实轨迹即可衡量对象伪影的 FLF2V-obj 指标。在这些新评测协议以及 VBench 上，Search2Motion 都持续优于已有基线方法。

**Limitations / 局限性**
- EN: Because the approach relies on first-last-frame priors and target-frame construction quality, its robustness for highly complex motions or difficult insertion/inpainting cases remains an open question.
- ZH: 由于该方法依赖首尾帧先验以及目标帧构建质量，其在高度复杂运动或困难插入与修复场景中的鲁棒性仍有待验证。


## 2. The Unreasonable Effectiveness of Text Embedding Interpolation for Continuous Image Steering
- Authors：Yigit Ekin, Yossi Gandelsman
- Comments：Project Page: https://yigitekin.github.io/diffusion-sliders
- First：2026-03-18T17:57:53+00:00；Latest：2026-03-18T17:57:53+00:00
- Abs：https://arxiv.org/abs/2603.17998v1
- PDF：https://arxiv.org/pdf/2603.17998v1
- Code：https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces
- Project：https://yigitekin.github.io/diffusion-sliders

**中文翻译**
- 标题：用于连续图像操控的文本嵌入插值的非凡有效性
- 摘要：我们提出了一个无需训练的框架，用于在测试时对文本条件生成模型进行连续且可控的图像编辑。与依赖额外训练或人工用户干预的先前方法不同，我们发现，仅在文本嵌入空间中进行简单操控，就足以实现平滑的编辑控制。给定一个目标概念（例如增强照片真实感或改变面部表情），我们使用大型语言模型自动构造一小组去偏的对比提示词对，并据此在生成器的文本编码器空间中计算一个操控向量。随后，我们将该向量直接加到输入提示词表示上，以沿所需语义轴控制生成。为实现连续控制，我们提出一种弹性范围搜索过程，可自动识别有效的操控幅度区间，避免操控不足（无编辑）和操控过度（改变其他属性）。在该区间内加入同一向量的不同比例版本，可得到平滑且连续的编辑。由于我们的方法仅修改文本表示，因此能够自然泛化到各种文本条件模态，包括图像和视频生成。为量化操控的连续性，我们引入了一种新的评估指标，用于衡量不同编辑强度下语义变化的一致性。我们比较了不同方法的连续编辑行为，发现尽管我们的方法简单且轻量，但其效果可与基于训练的替代方案相当，并优于其他无需训练的方法。
