### [中文]
**中文翻译**
- 标题：Search2Motion：通过注意力共识搜索实现免训练的对象级运动控制
- 摘要：我们提出 Search2Motion，这是一种用于图像到视频生成中对象级运动编辑的免训练框架。不同于以往需要轨迹、边界框、掩码或运动场的方法，Search2Motion 采用基于目标帧的控制方式，利用首末帧运动先验，在无需微调的情况下实现对象重定位并保持场景稳定性。通过语义引导的对象插入和鲁棒的背景修复，可实现可靠的目标帧构建。我们进一步表明，早期步骤的自注意力图能够预测对象与相机动态，提供可解释的用户反馈，并由此提出 ACE-Seed（用于早期步骤种子选择的注意力共识），这是一种轻量级搜索策略，无需前瞻采样或外部评估器即可提升运动保真度。鉴于现有基准常将对象运动与相机运动混淆，我们引入了 S2M-DAVIS 和 S2M-OMB，用于稳定相机、仅对象运动的评估，并提出 FLF2V-obj 指标，在不需要真实轨迹的情况下分离对象伪影。Search2Motion 在 FLF2V-obj 和 VBench 上始终优于各类基线方法。

**Summary / 总结**
- EN: This paper addresses the difficulty of controlling object-level motion in image-to-video generation without relying on costly annotations such as trajectories, boxes, masks, or motion fields, and without disturbing the rest of the scene. It proposes Search2Motion, a training-free framework that performs target-frame-based control using first-and-last-frame motion priors, with semantic-guided object insertion and background inpainting to build reliable target frames, and uses early-step self-attention as a predictor of object and camera dynamics to guide ACE-Seed, a lightweight attention-consensus search for better seed selection. Experimentally, the authors introduce S2M-DAVIS and S2M-OMB for stable-camera object-motion evaluation and FLF2V-obj metrics to isolate object artifacts, and report that Search2Motion consistently surpasses baseline methods on both FLF2V-obj and VBench.

## 2. The Unreasonable Effectiveness of Text Embedding Interpolation for Continuous Image Steering
- Authors：Yigit Ekin, Yossi Gandelsman
- Comments：Project Page: https://yigitekin.github.io/diffusion-sliders

- Code：https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces

### [中文]
**中文翻译**
- 标题：用于连续图像引导的文本嵌入插值的不合理有效性
- 摘要：我们提出了一种无需训练的框架，用于在测试时对文本条件生成模型进行连续且可控的图像编辑。不同于以往依赖额外训练或人工用户干预的方法，我们发现，仅在文本嵌入空间中进行简单引导，就足以实现平滑的编辑控制。给定一个目标概念（例如增强照片级真实感或改变面部表情），我们使用大语言模型自动构造一小组去偏的对比提示词对，并据此在生成器的文本编码器空间中计算一个引导向量。随后，我们将该向量直接加到输入提示的表示上，以沿所需语义轴控制生成。为实现连续控制，我们提出了一种弹性范围搜索过程，可自动识别有效的引导幅度区间，从而同时避免引导不足（无编辑）和引导过度（改变其他属性）。在该区间内加入同一向量的不同比例版本，可产生平滑且连续的编辑。由于我们的方法仅修改文本表示，因此可自然泛化到各类文本条件模态，包括图像和视频生成。为量化引导的连续性，我们引入了一种新的评估指标，用于衡量不同编辑强度下语义变化的均匀性。我们比较了不同方法的连续编辑行为，发现尽管该方法简单且轻量，其效果可与基于训练的替代方案相当，并优于其他无需训练的方法。

**Summary / 总结**
- EN: This paper is motivated by the need for continuous, controllable image editing in text-conditioned generative models without extra training or manual tuning at test time. The authors propose a training-free method that uses a large language model to generate a small set of debiased contrastive prompt pairs for a target concept, computes a steering vector in the model’s text-embedding space, and adds scaled versions of that vector to the input prompt representation; an elastic range search then automatically selects a useful interval of steering strengths to enable smooth edits while avoiding under- or over-steering. Experiments on text-conditioned generation, including image and video settings, show smooth semantic control, and with a new continuity metric the method is reported to be comparable to training-based approaches while outperforming other training-free baselines in continuous editing behavior.
- ZH: 本文的动机是实现文本条件生成模型在测试时无需额外训练或人工反复调参的连续、可控图像编辑。作者提出一种免训练方法：先利用大语言模型围绕目标概念自动构造少量去偏置的对比提示词对，在生成器的文本编码空间中计算转向向量，再将其按不同强度直接加到输入提示的表示上；同时设计弹性范围搜索，自动找到既不会编辑不足也不会过度改变其他属性的有效强度区间，从而实现平滑连续的控制。实验表明，该方法不仅可用于图像，也能自然泛化到视频等文本条件生成任务；在作者提出的连续性评价指标下，其连续编辑表现可与基于训练的方法相比，并优于其他免训练基线。

### [English]
**Summary / 总结**
- EN: This work is motivated by the need for continuous and controllable image editing in text-conditioned generative models without extra training or manual tuning at inference time. The authors propose a training-free method that uses a large language model to generate a small set of debiased contrastive prompt pairs for a target concept, computes a steering vector in the model’s text-embedding space, and adds scaled versions of this vector to the input prompt; an elastic range search automatically finds effective steering magnitudes that avoid both weak edits and unwanted attribute changes. Experiments on text-conditioned generation, including image and video settings, show that this simple embedding-interpolation approach produces smooth semantic edits, achieves competitive performance with training-based methods, outperforms other training-free baselines in continuous editing behavior, and is supported by a new metric measuring the uniformity of semantic change across edit strengths.
